What are the system requirements?

Windows 10 or 11 on an x64 processor. If WebView2 Evergreen is missing, setup downloads it from Microsoft.

Do I need administrator permissions?

Choose Install for me only to install for your account. Select Install for all users to install in Program Files with Windows approval.

Can I keep my Brisa profile?

Close earlier versions before opening the new one. Brisa uses the local profile it already created on Windows.

How do I enable local translation?

Install Node.js in the default Windows directory. The first translation downloads the language model. Brisa processes the page text on your computer.

Is the installer digitally signed?

The release notes say whether the installer is Authenticode-signed. Use the published SHA-256 checksum to verify the file.
