¿Qué necesito para instalarlo?

Windows 10 u 11 con procesador x64. Si falta WebView2 Evergreen, el instalador lo descarga de los servidores de Microsoft.

¿Necesito permisos de administrador?

Elige Instalar para mí solamente para usar tu cuenta. Selecciona Instalar para todos los usuarios para instalar en Archivos de programa con la autorización de Windows.

¿Puedo conservar mi perfil de Brisa?

Cierra las versiones anteriores antes de abrir la nueva. La instalación usa el perfil local que Brisa ya creó en Windows.

¿Cómo activo la traducción local?

Instala Node.js en el directorio predeterminado de Windows. La primera traducción descarga el modelo de idioma. El texto de la página se procesa en tu equipo.

¿El instalador tiene firma digital?

Las notas de la versión indican si el instalador tiene firma Authenticode. Usa el SHA-256 publicado para comprobar la integridad del archivo.
