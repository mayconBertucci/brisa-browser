Abas e favoritos

Fixe suas abas mais usadas. Arraste marcadores para ordenar ou guardar em pastas. Use a estante para liberar abas e reabrir a página depois.

Barra de endereços

Instale o Brisa

Baixe o instalador, abra o arquivo e siga as etapas em português. O Brisa fica disponível no menu Iniciar da sua conta do Windows.

↓ Baixar Brisa 1.0.5 Verificação SHA-256
O que preciso para instalar?

Windows 10 ou 11 com processador x64. Se o WebView2 Evergreen estiver ausente, o instalador usa a internet para instalá-lo pelos servidores da Microsoft.

Preciso ser administrador?

Escolha Somente para mim para instalar na sua conta. Selecione Para todos os usuários para instalar em Arquivos de Programas com a autorização do Windows.

Posso manter meu perfil do Brisa?

Feche versões anteriores antes de abrir a nova. A instalação usa o perfil local que o Brisa já criou no Windows.

Como ativo a tradução local?

Instale o Node.js no diretório padrão do Windows. A primeira tradução baixa o modelo de idioma. O texto da página é processado no computador.

O instalador tem assinatura digital?

O instalador 1.0.5 está sem assinatura Authenticode. O SmartScreen pode sinalizar reputação desconhecida. A soma SHA-256 publicada permite conferir a integridade do arquivo.
